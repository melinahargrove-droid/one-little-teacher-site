Overview

01 · LISTEN

Hear the picture names

Listen to the rhyme question and each answer choice. Replay the question whenever needed.

02 · MATCH

Find the rhyming friend

Tap the picture whose name rhymes with the target. An incorrect answer keeps the same choices for another try.

03 · PRACTICE

Build confidence

Use Show me for a clue. After a match, choose Next turn when ready to continue.

What’s included

  • One self-contained HTML rhyming game with embedded illustrations and recorded narration.
  • Twelve rhyme pairs and adjustable games from 1 to 50 turns.
  • Two, three or four picture choices; optional written words; hints and replay controls.
  • A START HERE text guide.

Standalone learning game, not a book companion. No separate printable worksheets are included.

How to use

  1. Unzip the download and open the HTML file in a current browser.
  2. Select Let’s play to hear the introduction and begin.
  3. Listen to the question, then choose the picture that rhymes.
  4. Use Teacher tools to adjust the game; Home returns to the opening.
