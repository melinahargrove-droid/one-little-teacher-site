Overview

01 · FIND

Find a Color

Listen to or read the color clue, then tap the matching object.

02 · SORT

Sort the Baskets

Choose a loose object, then tap the basket with the same color. Sort six or nine objects across three baskets.

03 · COLLECT

Fill a Color Basket

Tap every object that matches the basket’s color to collect a matching group.

What’s included

  • One standalone HTML game in a ZIP download.
  • Three modes: Find a Color, Sort the Baskets, and Fill a Color Basket.
  • Red, yellow, blue, green, orange, and purple, with a first-three-colors option.
  • Embedded recorded narration, replay directions, Home, full-screen control, and teacher settings.

A free standalone game, not a book companion. No separate printable worksheets are included.

How to use

  1. Unzip the download and open the HTML file in Chrome or Edge.
  2. Choose a color set and object style, then select an activity.
  3. Tap or click to find, sort, or collect matching colors.
  4. Use Next for another round and Home to change activities. Teacher settings offer color words, voice, sound, motion, and sorting quantity choices.
