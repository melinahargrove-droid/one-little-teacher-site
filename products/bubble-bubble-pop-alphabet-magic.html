What’s included

How to use

  1. Unzip the download and open the HTML game in a browser.
  2. Choose the learning mode, letter pool and number of turns in Teacher Settings.
  3. Tap any letter bubble and listen to the picture reveal.
  4. Select Next to continue. Letters do not repeat until the selected pool has been used.
