Overview

01 · SHAKE

Count the two colors

Shake and spill the counters, then count the yellow and red groups. Touch counters to mark them, or use Count again to clear the marks.

02 · MAKE

Build the same two parts

Add one matching feather for each counter. Tap, use the plus buttons, or drag feathers onto the turkey. Remove a feather to revise your work.

03 · DISCOVER

Find another way

When both color groups match, the completed number sentence appears and the turkey gobbles. Saved discoveries show different ways to make the same whole.

What’s included

  • One standalone offline HTML game in a ZIP download.
  • Recorded directions and completed number sentences, with a replay control.
  • Two-color counters, matching feather interactions and a saved discoveries collection for each whole.
  • Teacher choices for wholes 2–10, specific color combinations, counter totals and sound effects.

The game has a built-in Print our discoveries option. No separate worksheet PDF is included.

How to use

  1. Unzip the download and open the HTML file in a browser.
  2. Choose a whole number, then start the activity. Teacher settings also lets you choose a particular color combination.
  3. Count the two color groups and add the same number of yellow and red feathers.
  4. Shake again to find another combination, or open Ways we found to revisit saved discoveries.
