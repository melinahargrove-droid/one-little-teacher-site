Which Has More?

Which group has more? Sometimes fewer!

Ways to use it

  • Compare two groups and decide which has more — or fewer.
  • Use counting markers to check each group before choosing.

How to play

  1. Choose the highest number and how many questions in Teacher Setup.
  2. Count both groups.
  3. Tap the group that has more, or fewer when asked.

Practical details

Teacher Setup sets the highest number to count to (5, 10, or 20), the number of questions, and whether counting markers show. Sound and markers can be toggled during play.
