Overview

01 · COUNT

Count Together

Touch each object once to count along. Number markers help children keep track of the objects they have counted.

02 · CHOOSE

How Many?

Count the objects in the basket and choose the matching number. Children can tap objects to help keep track.

03 · BUILD

Make a Set

Tap to add objects to the basket, or tap inside to take one out. Use Check when the set is ready.

What’s included

  • One standalone HTML game in a ZIP download.
  • Three modes: Count Together, How Many?, and Make a Set.
  • Two number ranges and four object choices.
  • Embedded recorded narration, replay directions, Home, full-screen control, and teacher settings.

A free standalone game, not a book companion. No separate printable worksheets are included.

How to use

  1. Unzip the download and open the HTML file in Chrome or Edge.
  2. Choose a number range and counting objects, then select an activity.
  3. Tap or click to count, choose a numeral, or build the requested set.
  4. Use Next for another basket and Home to change activities. Teacher settings offer voice, sound, and motion choices.
