Overview

01 · LOOK

Count the collection

Squirrel has a collection of acorns to count. Start small or choose a larger range as children become more confident.

02 · COUNT

Keep track of each acorn

Tap acorns to add counting markers, or use Count with me for support. Each acorn counts once, even if it is tapped again.

03 · CHOOSE

Match the number

Choose one of three number signs. A correct answer waits for Next acorns; an incorrect answer keeps the same collection for another try. There are no timers or penalties.

What’s included

  • One standalone offline HTML counting game in a ZIP download.
  • Three counting ranges, optional zero, and teacher-controlled round count.
  • Tap-to-count markers, recorded instructions and feedback, replay control, and Count with me support.
  • Scattered and tidy-row acorn arrangements, plus built-in printable counting practice with an answer key.

Counting practice is printed from the game’s Teacher tools. No separate worksheet PDF is included. The game is standalone, not a book companion.

How to use

  1. Unzip the download and open the HTML file in a browser.
  2. Choose Count to 5, Count to 10 or Count to 20. Open Teacher tools to customize the range and support.
  3. Count the acorns, tapping them to mark each one if helpful. Choose the matching number sign.
  4. After a correct match, select Next acorns. Use Home to return to the opening choices.
