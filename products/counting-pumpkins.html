Count one at a time

Tap each pumpkin to count it once. Practice connecting one number word with one object.

02

Find how many

Count the whole group, then use the final count to tell how many pumpkins are there.

Choose from three numerals to match the group. Turn on zero for practice with an empty farm.

Count. Choose. Try another round.

Count the pumpkins

Look at the pumpkins arranged in the ten-frame. Tap each pumpkin once as you count. Use Count with me for narrated counting support.

Choose a numeral

Select the number that matches the group from three choices. The game responds to the answer.

Continue together

The teacher chooses Next to move on, leaving time to talk about each group before another round.

You set the challenge. Choose a 1–5 or 1–10 counting range, decide whether to include zero, and select 1–40 rounds. Use a shorter session for a quick practice turn or a longer one for small-group play.
