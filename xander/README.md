# Xander's Secret Arcade — preview

This folder is reserved for the arcade preview. It is isolated on the `xander-arcade-preview` branch, so the live site is unchanged.

Copy the contents of `Xanders_Secret_Arcade.zip`'s `xanders_arcade/` directory here, retaining `index.html` and `fuzzy-bug-math-factory/index.html`.

When Netlify builds a deploy preview of this branch, test `/xander/` on a phone using HTTPS. Confirm tilt sensor status and gameplay before merging to `main`.

The arcade is unlisted, not password-protected. Do not treat the URL as private.
